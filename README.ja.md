## 作ったもの

- **宇伴** は QQ で話せる AI の相棒です。決まった時間に声をかけてくれます。いくつかのメッセージに分けて話したいときは、最初にそう伝えておくと、話し終わった合図をするまで返事を待ってくれます。[宇伴を見る](https://github.com/xiaohantiko/yuban-showcase)
- **漫序 Studio** は Mac 向けに作ったモーションコミック制作ツールです。サンプルの『灯塔来信』では、1枚のキャラクターカードから始めて、参考画像を選び、登場シーンの動きを絵コンテに書き込めます。[漫序 Studio を見る](https://github.com/xiaohantiko/manxu-studio-showcase)
- **易历** を作っていて面白かったのは、四柱推命の「年柱」が切り替わるタイミングです。生年月日が同じでも、立春を迎える瞬間の前に生まれたか後に生まれたかで、年柱が変わることがあります。出生地のタイムゾーンと節入りの時刻をもとに、Mac と Windows のどちらでもオフラインで命式を出せます。[易历を見る](https://github.com/xiaohantiko/yili-macos)
